# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

This is **My \*Space** — a productivity blog platform for \*Space Discord server members, built with SvelteKit (Svelte 5), TypeScript, and Tailwind CSS 4 on Cloudflare Pages. Discord OAuth (Auth.js) gates everything; the session carries the user's Discord guild IDs so access can be checked against \*Space membership. Use npm (not the README's yarn), Node 20, and keep the dev server on its pinned port 8788.

**Refer to [AGENTS.md](AGENTS.md) for canonical commands, architecture, and rules.**
